### Added

- **The 328P and 32U4 fall back to `PREV`** (#52). At `OTA_BEGIN` the
  application backs the running image up to the store's `PREV`
  (`src/core/ota_prev.c`, new HAL read `tfw_hal_flash_read`); the 2560 links
  `ota_prev_none.c`. A `BOOT_STORE=1` tfw-boot without `BOOT_AB` links
  `boot/boot_prev.c`: a trial found at reset, and a pending image the gate
  refuses, copy `PREV` back and store `GOOD` with `FAILED`; the restored image
  is evaluated as every boot and, refused, halts. Host tests only
  (`test_boot_prev`, `test_ota_stage`). The simavr `prev` row is written and
  not run: the 328P's row is not in `BOOT_SUPPORTED` until its boot size is
  measured. Open, recorded in `docs/ota/architecture.md`: no fallback flag is
  written.
- **tfw-boot clears the store's `MARK` at a fallback** (#52, owner ruling
  2026-10-17, item 56). `tfw_boot_stage_forget` (`boot/boot_stage.c`)
  programs the `MARK`'s magic to zero before a trial that ended, or a refused
  pending image, falls back, so the failed image is not taken from the store
  again; a clear cut short leaves no `MARK`. Host tests in `test_boot_stage`.
