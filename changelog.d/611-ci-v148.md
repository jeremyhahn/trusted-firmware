### Changed

- CI: `ci.yml` moves to ci-template v1.48 (customized), and `nightly.yml` to
  nightly-template v1.12 (customized), with the template's scripts (#611).
  - The template merge silently dropped the Signatures job and its CI Gate
    check line (the template removed them; this repository had kept them
    unchanged, so no conflict showed). Both are restored.
  - Integration now runs on every PR except a docs-only one (the template's
    v1.41 condition), so its CI Gate check is the `docs` class.
  - "Free hosted runner disk" runs only on GitHub-hosted runners: v1.48 can
    send overflow jobs to self-hosted hosts, where its `sudo rm -rf` must not
    run.
  - Nightly FIPS builds and tests the `xkms/` and `sdk/go` modules through
    the Unit job's `xkms-coverage` and `sdk-coverage` targets; there is no
    root Go module, so the template's bare `go test ./...` ran nothing.
