### Changed

- CI: `ci.yml` moves to ci-template v1.51 (customized), and `code-review.yml`
  to code-review-template v5.12.8 (#611, DS-9792).
  - Runner selection reads a run or job list the Actions API returns short of
    its total as a lower bound, so a full hosted pool overflows to the Dells
    again (v1.50).
  - `Runner labels (ruling 633)` also reads every runs-on under
    `pull_request_target`, where a fork's head never reaches a self-hosted
    runner (v1.51).
  - The code review cancels a PR's runs on an older head when a new head is
    pushed, only runs older than its own (v5.12.8), and a twin's passing gate
    re-runs a newer run's red gate on the same head (v5.12.7).
