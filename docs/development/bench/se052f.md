order of 2026-10-19 (CA m767): the bench inventory matches the SPEC rows. The
board is the hardware for row `secure-element-se05x` ([`../../SPEC.md`](../../SPEC.md)),

## The part

The SE05x documents are listed in
[`../../reference/README.md`](../../reference/README.md). Read on 2026-11-12:
the SE052 data sheet, Rev. 1.5 (the SE052F is its FIPS variant, §2), and
AN14277, *SE052 Configuration Details*, Rev. 1.0, which gives the SE052F's
configuration. Not read: AN12543, the IoT applet APDU specification AN14277
names, and UM11225 (both behind NXP's sign-in), and GlobalPlatform's
GPC_SPE_172 (behind its licence form). AN12413 as NXP publishes it is the
SE050's, so nothing is taken from it. A value is filled only from a document
read, cited by section; the rest stay blank, with the document they will be
read from. The onboarding ADR,
[`../../multi-arch/adr-se052f-onboarding.md`](../../multi-arch/adr-se052f-onboarding.md),
lists what each is for.

| | Value | Source |
|---|---|---|
| Host interface | I2C target up to 3.4 Mbit/s, using T=1 over I2C; the configuration selects the GlobalPlatform flavour ("GP 0.39 flavour") | data sheet §3.1, §9.1; §13.3, Table 12 (`I2C_SPI_PARAMS`). Also plug-and-trust `v04.07.01`, `README.rst`, "Introduction" |
| I2C address | `0x48` (7-bit target address, as configured) | data sheet §13.3, Table 12 (`I2C_SLAVE_ADDRESS`) |
| Supply voltage | VDD 1.62 V to 5.5 V (classes A 5 V, B 3 V, C 1.8 V); VIN, which supplies the SDA and SCL pads, 1.65 V to 3.6 V, those pads 3.63 V at most | data sheet §12, Tables 7 and 8; §11, Table 6; §13.4, Table 13; VIN's pads, §5.1, Table 2 |
| Curves and algorithms | ECDSA, ECDH, ECDHE on NIST, Brainpool and Koblitz curves of 224 bits and more; RSA 2048, 3072 and 4096; AES-128/192/256 (CBC, CTR, ECB, CCM, GCM); SHA-224 to SHA-512; HMAC, CMAC, GMAC; HKDF, PBKDF2, TLS KDF | AN14277 §2.1.1, Table 1; §2.4 (FIPS: no RSA 1024, no SHA-1 signature, no ECC key under 224 bits) |
| Device certificate | NXP-provisioned, die-individual ECC256 keys with NXP-signed certificates: the attestation key `0xF0000012`, certificate `0xF0000013`; the connectivity keys `0xF0000000` and `0xF0000002`, certificates `0xF0000001` and `0xF0000003`; each certificate a DER X.509v3 in a zero-padded binary file | AN14277 §2.4, Table 7; §2.6, Table 8; §2.7, Table 9 |
