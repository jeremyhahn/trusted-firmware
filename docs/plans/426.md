# Plan: row mcxn947 (#426)

## Objective

Build the row PR for SPEC row `mcxn947` (NXP FRDM-MCXN947, Cortex-M33 with
the EdgeLock secure subsystem): fold the row's seven open PRs into
`row/426-mcxn947`, check every acceptance clause of the row against the
tree, measure the tfw-boot image's fit in its 32 KB region, and set the row
to `shipped` only if every clause is met.

## Slices, in order

1. Fold #375 (row/mcxn947-adc); resolve its conflicts with main keeping
   both sides. Test: `make host-test` (test_mcxn94x_adc).
2. Fold #392 (row/mcxn947-tone). Test: test_mcxn94x_tone.
3. Fold #399 (row/mcxn947-eeprom); resolve conflicts. Test:
   test_mcxn94x_eeprom.
4. Fold #408 (row/mcxn947-gpio-test). Test: test_mcxn94x_gpio.
5. Fold #413 (row/mcxn947-pulse); resolve conflicts. Test: host-test.
6. Fold #419 (row/mcxn947-uart-test); resolve conflicts. Test:
   test_mcxn94x_uart.
7. Fold #420 (row/mcxn947-soc-test); resolve conflicts. Test: test_mcxn_soc.
8. Check each acceptance clause against the tree (board id 0x46 soft tier;
   clock, LPUART4, GPIO, watchdog HAL; firmware-matrix and CI step; host
   tests of pin table and LPUART baud arithmetic; tfw-boot row
   `frdm-mcxn947:soft:soft:p256-soft:0:0` on polled LPUART4 and the
   boot-ROM flash writer, register and ROM models, SDK citations). Fix what
   a host build or host test can prove.
9. Measure the tfw-boot image's size against the 32 KB region and record
   it in docs/SPEC.md row mcxn947 and docs/boards/frdm-mcxn947.md.
10. Status cell: `shipped` only if no clause is open.

Gates: `make host-test`, `make board-sweep`, `make firmware-matrix`,
`make bootloader-check`, `make lint`, `make lint-arch-leak`.

## Departures

- The fold heads were the clone's `refs/remotes/origin/row/mcxn947-*`
  (descendants of the listed heads). #408's current head is not a
  descendant of the listed 0bd5e3c5a (its main merge was redone), so the
  listed head is folded; its later test commit is left to the coordinator.
- Folding #392 after #375 puts the tone on board pin 8 (A2..A4 are 5..7).
- The 32 KB fit is already measured on main (#398, 8492 / 32768 flash,
  board page "tfw-boot"); no boot file changed since. The lane has no
  arm-none-eabi-gcc, so firmware-matrix, bootloader-check and a fresh
  measurement are left to CI.
- docs/SPEC.md is write-protected in this lane: the row's "not yet
  measured" sentence and its status are left to the coordinator. The status
  stays `in progress` regardless: the board runs and the EdgeLock subsystem
  are open.
- Slice 2: #375's head 9d42cde0 (a main merge) is folded. #408's head
  181f8b93 is not: it merges main's #434, which changes
  .github/workflows/ci.yml, and the lane may not commit that path. Leaving
  that hunk out would make the row revert #434. Resolution for whoever folds
  it: board files, cm_regs.h, the tone test and the board page as the row has
  them (pin 8, one Tone section); mk/host.mk with the row's
  HOST_MCXN94X_CFLAGS and ADC rule; mk/firmware.mk with the row's
  EEPROM_HAL_SRCS (hal_src already picks the nrf54l's copy) and no
  HAL_EEPROM_OTHER. host-test, board-sweep, boot-test and lint passed on that
  tree.
- Fold ref cdx-375b is dropped: an unfinished edit that moves the SDK line
  citations of the ADC block in soc_regs.h by one, stopping at
  ADC_TCTRL_TCMD. The pinned header is not in the lane, so the shift cannot
  be checked.
- Fold ref hosttest-mcxn-uart is dropped: an earlier draft of
  test_mcxn94x_uart.c, superseded by the suite #419 folded.
