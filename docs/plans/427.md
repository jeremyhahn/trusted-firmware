# Plan: row nrf54l15 (#427)

## Objective

Build the row PR for SPEC row `nrf54l15`: fold the row's open PRs into
`row/427-nrf54l15`, with no PWM/tone takeover on LED1, check every
acceptance clause against the tree, and mark the row `shipped` only if
every clause is met by this PR.

## Slices, in order

1. Fold #385 (row/nrf54l15-eeprom): EEPROM over TWIM beside #369's TWIM
   lines. Test: test_nrf54l_eeprom in `make host-test`.
2. Fold #386 (row/nrf54l15-pwm): PWM HAL. Test: test_nrf54l_pwm.
3. Fold #407 (row/nrf54l15-gpio-test): GPIO model test. Test:
   test_nrf54l_gpio.
4. Fold #414 (row/nrf54l15-pulse): PULSE_IN / PULSE_CAPTURE through the
   Cortex-M SysTick timer. Test: the pulse tests.
5. Fold #418 (row/nrf54l15-uart-test): UARTE model test. Test:
   test_nrf54l_uart.
6. No PWM/tone takeover (ruling 109, Codex P1-2 on #386): fold #386's
   head 48359877f, whose 59f726ee7 drops the LED1 handoff and fails a
   start whose stop never lands with TFW_ERR_TIMEOUT; then revert the

   soc_tables.h stay main's. Test: test_nrf54l_pwm's
   test_a_stop_that_never_lands_fails_the_next_write.
6a. SAADC GPIO-to-analog: each read puts the pin's PIN_CNF back to reset
   (input, no pull, input buffer disconnected) before sampling. Test:
   test_nrf54l_saadc's
   test_a_read_resets_the_pins_gpio_configuration_before_sampling.
7. Clause check: memory map, clock, watchdog, UARTE console in the
   firmware matrix on the generic cortex-m HAL; tfw-boot soft row
   `nrf54l15-dk:soft:soft:p256-soft:0:0` built by `bootloader-check`.
8. `docs(spec):` row status, only if no clause is open. The clauses this
   row's PR can meet hold (folds, `bootloader-check`); DICE evidence on the
   KMU and TrustZone, and enrollment, are open, so the row is not shipped.
   Moving it from `future` to `in progress` needs a lane allowed to edit
   docs/SPEC.md.

Every fold head (#385, #386, #407, #414, #418) is an ancestor of the row;
main's #385 brought the EEPROM test rule, so host.mk keeps one copy.

Each conflicted fold is followed by `make host-test` before the next.
