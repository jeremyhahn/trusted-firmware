# Plan: row `imx95` (#428)

## Objective

Ship SPEC row `imx95` as one row PR on `row/428-imx95`: the NXP i.MX 95
(FRDM-IMX95-PRO) as a `cortex-m` board, with our firmware core on its
Cortex-M7 (`boards/frdm-imx95-m7`, provisional id 0x41).

## Slices, in order

1. Fold #388 (`row/imx95-i2c`): the LPI2C polled master, `soft:I2C=1`.
   Test: `test_imx95_lpi2c`.
2. Fold #395 (`row/imx95-pwm`): PWM on a TPM, `soft:PWM=1`. Tests:
   `test_imx95_tpm`, `test_board_frdm-imx95-m7_pwm`, `_pwm_base`,
   `_adc_pwm_base`.
3. Fold #403 (`row/imx95-tone`): GPT-backed tone, `soft:TONE=1`. Test:
   `test_imx95_gpt`.
4. Finish the tone: a second build of the GPT test at the board's zero base
   (`test_imx95_gpt_nobase`: every call refused, no register touched), and
   the tone paragraph in the design page's section 9.5.
5. Clause check against docs/SPEC.md row `imx95`: the board id in the
   Cortex-M range, the TCM map and A55 load addresses, LPUART3, RGPIO and
   WDOG5 with the soft root, built in CI; each SoC fact cited, or marked TO
   CONFIRM against IMX95RM on the design page.
6. Board slice (2026-11-14, read-only, CA ruling 583): the factory record
   (`docs/development/bench/frdm-imx95.md`), then each TO CONFIRM fact the
   live board answers marked with its source (design page 9.4.1, comments
   in `soc_regs.h`, `tpm.h`). No firmware runs on the board in this slice;
   the eMMC backup and a power-cycle boot log stay open.

Each fold is one `git merge --no-ff` commit; conflicts keep both sides.
After each conflicted fold, `make host-test` runs before the next.

## Open, not done here

- The EdgeLock secure enclave key tier (DICE root and keys in the enclave).
- AHAB verification of the M7 image as a signed container.
- SCMI to the System Manager on the M33, on the board.
- A board run: QEMU has no i.MX 95, and nothing here runs on a board.
- The platform image, its boot container and the System Manager
  configuration belong to trusted-imx95, not this repository.

While these are open, row `imx95` stays `in progress` in docs/SPEC.md.

## Out of scope

ROADMAP.md, other SPEC rows, .github/, and later pushes to the fold
branches (the coordinator folds them).
