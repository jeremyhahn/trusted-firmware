# Plan: SPEC row rp2350 (#429)

## Objective

The RP2350 on the Raspberry Pi Pico 2 W: the firmware core as a HAL
port, with DICE evidence on the part's OTP and secure boot, enrolled
through go-xkms into go-trusted-platform. The onboarding ADR stays
docs-only (#128). The owner lifted the AVR gate (#7) for the RP2350 by
ruling 697: its firmware features may be enabled on the board.

## Slices, in order

1. Done (#446): the per-item PRs (#366 I2C, #373 PWM, #380 ADC, #390
   tone, #393 flash EEPROM) folded into the row, each with its register
   model under test/model/cortex-m/rp2350/. The default image stays GPIO
   only; PWM, ADC, tone and EEPROM build in the `soft:PERIPH=1` row, I2C
   in `soft:I2C=1`.
2. The gate lift (ruling 697, branch `row/429-rp2350-gate-lift`):
   docs/SPEC.md's rp2350 row goes from future to in progress, naming the
   lift, and line 26 notes it; the onboarding ADR records it. The open
   Codex P1s of #446, #366 and #380 are checked against main: the ADC
   pin restore (`test_a_read_restores_the_pin_it_borrowed`), the I2C
   foreign STOP (`test_another_masters_stop_does_not_end_the_write`) and
   the tone retried alarm (`test_irq_alarm_fired_during_the_write_toggles_once`)
   are fixed and tested on main by #446's squash, so no code changes.
3. Enable the peripherals in the Pico 2 W's default image, now that the
   gate is lifted. Code half done (branch `row/429-rp2350-default-image`):
   `I2C ?= 1` and `PERIPH ?= 1`, `CM_FLASH_GATED_WHY` dropped so `make
   flash` refuses no row, `BOARD_ROWS` now `soft:I2C=0 soft:PERIPH=0`.
   Board half (lane rp2350-bench): the HIL boot and feature check.
   Before it, the picotool fix: mk/arch/cortex-m.mk's picotool save and
   load put `--ser` after the file and options, as picotool 2.1.1
   requires (scripts/test_cortex_m_flash.py's TestPicotoolArgOrder).
4. DICE evidence on the RP2350 OTP: the UDS/CDI seed read from OTP rows
   with the read lock, host-tested over an OTP model.
5. Secure boot: tfw-boot's row on the RP2350 boot ROM's signed-image
   path, and enrollment through go-xkms into go-trusted-platform. The
   row is marked shipped when slices 3 to 5 land.

## Tests per slice

- Slices 1 and 2: the rp2350 register-model host tests (adc, i2c, tone,
  pwm, eeprom) and the firmware build matrix for the pico2w board.
- Slice 3 adds the default-row build, scripts/test_rp2350_rows_mk.py's
  check that the default row links I2C, ADC, PWM, tone and flash EEPROM
  and that every row reaches `make flash`'s write path, and the bench
  feature check.
- Slices 4 and 5 add OTP-model and boot-path host tests; the enrollment
  path adds its integration target.

## Out of scope

- Running anything on the physical board in slice 2 (a later lane).
- The other HAL ports' rows.
