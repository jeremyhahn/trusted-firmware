# 456: xkms-adapter requirement audit

## Objective

SPEC row `xkms-adapter` is "in progress" with its issues (#28, #194) closed and
no open slice written down. Audit the row's text (docs/SPEC.md) and
docs/xkms-adapter/engineering.md against the code under `xkms/` and its tests,
so the row becomes a list of remaining slices or a recorded "done" claim the
owner can act on.

## Slices

1. Requirements table in docs/xkms-adapter/engineering.md: one line per
   requirement (SPEC row and engineering.md), with status (done / partial /
   not started), the implementing file under `xkms/` and the test (file and
   test name on main) that proves it. Every name is checked with `git grep`.
2. "Remaining slices" list below it: numbered, one sentence each, naming the
   files it would touch and the test that would prove it, and saying which
   need hardware, another project or an owner decision.
3. changelog.d/456-xkms-adapter-audit.md, one line.

No test is added: the audit is reading only, and its proof is that every
file and test it names exists on main.

## Out of scope

- Code, test, docs/SPEC.md and .github changes. Drift found in the SPEC row's
  text is listed as a slice for the owner, not edited.
- The slices themselves: each is a later lane.
