# Plan: #470, shrink the esp32 CI image

## Objective

The `esp32` target of build/docker/devcontainer/Dockerfile was 18 GB (DS-9146):
FROM Espressif's full ESP-IDF image, with Go and the module cache added on top
and nothing dropped. Make it the runtime `make esp32-build` and
`make esp32-qemu-test` need and no more.

## Slice 1 (this lane, one commit)

- `esp32-build` (build-only, FROM the ESP-IDF image by digest): idf-env.json
  restarted, `idf_tools.py install --targets=esp32,esp32c3,esp32p4` for the
  required tools plus cmake, ninja and both QEMUs; tool directories that
  `idf_tools.py export` does not name for those chips are removed; the git
  history of ESP-IDF and its submodules is removed, `version.txt` (checked
  against the image tag) kept in its place; docs/, dist/, caches removed.
- `esp32` (shipped, FROM ubuntu:24.04 by digest, the ESP-IDF image's own OS so
  the copied Python 3.12 environment runs): runtime apt packages only; COPY
  `/opt/esp` from esp32-build and `/usr/local/go`, `/opt/go` from base (one
  layer each, the chmod already done in base, so the module cache is not
  doubled); the IDF env vars, ENTRYPOINT and CMD restated.
- Tests: the image build is the test. The QEMU version check runs again on
  the final image's libraries, and the as-user probe now builds hello_world
  for esp32c3 (RISC-V) and esp32 (Xtensa).

## Paths the make targets use, and where each comes from

| Path (mk/arch/esp32*.mk, mk/platform-bake.mk) | In the esp32 image |
| --- | --- |
| `$IDF_PATH/export.sh`, `idf.py`, `tools/`, components | COPY /opt/esp (IDF_PATH=/opt/esp/idf) |
| `$IDF_TOOLS_PATH/tools/{riscv32,xtensa}-esp-elf`, esp32ulp-elf, esp-rom-elfs, cmake, ninja | COPY /opt/esp (IDF_TOOLS_PATH=/opt/esp) |
| `qemu-system-riscv32`, `qemu-system-xtensa` (esp32-qemu-test) | COPY /opt/esp, runtime libs by apt |
| `python`, `espsecure.py`, `espefuse.py`, esptool, cryptography (l0_seal.py, qemu_test.py) | COPY /opt/esp/python_env, python3 by apt |
| `$IDF_TOOLS_PATH/idf-env.json`, `/opt/esp/entrypoint.sh` | COPY /opt/esp, chowned as before |
| `go` (tfwprov, suit-emit, wirecheck), `/opt/go/mod` | COPY from base |
| `objcopy` (PLATBAKE_HEX2BIN), `make`, `git`, `ccache` | apt |

## Out of scope

- Moving any pin (ESP-IDF, QEMU, Go); tool-pins.sh, mk/docker.mk, .github,
  docs/SPEC.md unchanged. The image tag moves because the Dockerfile is hashed.
- The size number: no docker in the lane; the PR's CI image job is the build
  proof and the coordinator reports `docker image ls` against 18 GB.
