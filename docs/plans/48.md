# Plan: #48, row `esp32-p4` (the ESP32-P4 PoE board)

## Objective

The ESP32-P4 PoE board runs this firmware on silicon: layer 0 checks trailer
v1 at every boot, the app answers the wire protocol over its IP101 Ethernet,
and the security eFuses are provisioned only on the owner's decisions.

## Done

1. Board profile, partition table and the ESP-IDF port (`boards/esp32p4-poe/`,
   `src/hal/esp32/`, `boot/hal/esp32/`), with host tests and the QEMU board
   (`make esp32-qemu-test`). On main.
2. The EEPROM HAL on the host (`test_esp_hal_eeprom`). On main.
3. Bench HIL-0 (`docs/development/bench/esp32-p4.md`): read-only record before
   any write, the `sdkconfig.hil0` build, the four images and the four data
   sectors, the boot log (layer 0 `verified`, the app started), the eFuse
   summary unchanged after. Branch `row/48-esp32-p4`, PR #442.

## Open clauses, in order

1. **Network link.** A static-address overlay for the board on the bench
   network (`$HOME/p4-static.defaults`, HIL-0 step 2), rebuild, HIL-0 step 3,
   then step 4's link-up line and `wirecheck -board 0x80 -tier 0` (PING,
   CAPS, SYS_INFO). Needs the overlay from the coordinator; the bench network
   has no DHCP server. Test: the bench page's run table and `wirecheck: ok`.
2. **HIL-1: burn the UDS** into the `HMAC_UP` key block. Owner decision.
3. **HIL-2: the secure-boot key digest.** Owner decision.
4. **HIL-3: flash encryption**, release or development mode. Owner decision.
5. **HIL-4: advancing the eFuse floor** (`SECURE_VERSION`). Owner decision.
6. **Item 76:** the go-xkms change it needs, in go-xkms first.

Each HIL step records the eFuse summary before and after on the bench page;
an eFuse cannot be put back, so none runs without the owner's written
decision.

## Out of scope

- The C6 coprocessor's radio (held in reset, never enabled).
- The pin peripherals on silicon (`hal_gpio.c`, `hal_adc.c`, `hal_pwm.c`,
  `hal_tone.c`, `hal_bus.c`, `hal_pulse_rmt.c`): their own rows.
- `docs/SPEC.md`'s status cell: it changes when every clause above is met.
