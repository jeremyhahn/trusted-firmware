## Objective

requirements to `docs/esp32/engineering.md`, which has a Row status table but
no numbered list of what remains, so no lane can be seated on the row. This
lane checks each line of that table against the code and tests on main
(every file and test it names exists, every line reference is current) and
adds a numbered "Remaining slices" list, so a lane can be seated on the row or
the owner can call the runnable part done.
