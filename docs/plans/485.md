# Plan: SPEC row esp32-p4 audit (#485)

## Objective

Audit each requirement of SPEC row `esp32-p4` (`docs/SPEC.md` line 52)
against main's code and tests, and record the result in
`docs/multi-arch/esp32-p4-engineering.md`: the requirements table (Row status)
re-checked, with the targets it names located, and a numbered "Remaining
slices" list, as #456-#461 and #481 did. Docs only; no hardware (ruling 746,
DS-9193).

## Slices

1. **The audit** (this slice, one commit):

     table names is checked to exist on main; the `make` targets get their
     line in `mk/`;
   - a counts line and an audit note under the table;
   - "Remaining slices": what is left, in order, each with the files it
     touches, the test or bench step that proves it and who decides it;
   - a `changelog.d/485-esp32-p4-audit.md` entry.
   Test: none runs code; the proof is that each named path, test and target
   resolves on main (checked by hand in the slice, listed in the commit).
