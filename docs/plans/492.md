# #492: unit test for the ESP32 60 s OTA trial deadline

## Objective

docs/ota/engineering.md Remaining slices item 8: the ESP32 port's 60 s trial
deadline has no named test. Add host unit cases in test/unit/test_esp_ota.c,
against the mocks the file already uses (hal_mock time, esp_ota_mock).

## Slices

1. test/unit/test_esp_ota.c, src/core/ota_trial.c compiled into the suite:
   - test_a_confirm_before_the_deadline_keeps_the_image: confirm at 59.999 s,
     no reset at or after 60 s, the image stays VALID.
   - test_no_confirm_at_the_deadline_resets_into_the_rollback: no reset at
     59.999 s, one reset at 60 s, the image still PENDING_VERIFY.
   - mutation check: TRIAL_MS * 1001u fails the rollback case (lane log).
   - mk/host.mk: the test_esp_ota link line filters out the included
     ota_trial.c. ccdeps.sh records it in the .d file, so an incremental
     rebuild would link it twice. This is the idiom test_mps2_pwm uses.
     It departs from the brief's file list; the fix is needed for the test.
   - changelog.d/492-esp-trial-deadline.md.

## Out of scope

No change to src/ or docs/SPEC.md; no hardware run.
