# Plan: #496, rp2350 slice 2, the datasheet checks left open

## Objective

`src/hal/cortex-m/rp2350/soc_regs.h` marks the converter's rows (ADC, its
reset bit, clk_adc and the PLL_USB that feeds it) `TODO(datasheet)`, and
the PWM register numbers were written without the datasheet open. A wrong
literal would only show on the bench. This slice matches each against the
copied [RP-DS] (`docs/reference/rp2350-datasheet.pdf`, release 8), corrects
any literal that differs and removes the TODO where it matches.
Remaining slice 2 of `docs/boards/rp2350-pico2w.md` (audit #480).

## Slices

1. This plan.
2. `soc_regs.h`: every `TODO(datasheet)` row and the PWM block checked
   against [RP-DS] release 8, the table beside each group; the board page's
   PWM paragraph and converter table updated to say what was matched; one
   entry in `changelog.d/496-rp2350-datasheet.md`.

   Tests: `test/unit/test_rp2350_adc.c` and `test/unit/test_rp2350_pwm.c`
   under `make unit-test`, their expectations changed only where a literal
   is corrected.

## Out of scope

- Any value outside the ADC, clk_adc, PLL_USB and PWM rows.
- Hardware: no reading or PWM output is taken on the board (slice 3).
- OTA_CONFIRM to tfw-boot (slice 1).
