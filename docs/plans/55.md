# Plan: #55, W5100 socket 1 map pinned against the datasheet

## Objective

src/net/w5100.c maps socket 1, the DHCP client's UDP socket: registers at
0x0500, TX ring 0x4800-0x4FFF, RX ring 0x6800-0x6FFF. No test compares those
frames with the datasheet literal, so dropping the TX1 wrap mask passes every
W5100 suite. Pin them in test/unit/test_w5100_spi_mutate.c.

## Slices

1. Test only: three tests in test/unit/test_w5100_spi_mutate.c, in the style
   of the socket 0 ones:
   - test_socket1_registers_sit_at_0x0500 (frames F0 05 01 20, 0F 05 28 00);
   - test_socket1_tx_buffer_wraps_into_0x4800_0x4fff (0x0000, 0x07FF,
     0x0800, 0x1234, 0xFFFF);
   - test_socket1_rx_buffer_wraps_into_0x6800_0x6fff (0x0000, 0x07FF,
     0x0800, 0xABCD).
   Each is shown to fail against its mutant of w5100.c:36-38 (reverted).
   changelog.d/55-w5100-socket1-map.md, one Added entry.

## Out of scope

- Any change to src/ (the map is correct; only the test is missing).
- W5500 maps, sockets 2 and 3, hardware runs.
