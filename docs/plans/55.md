# Plan: #55, W5100 socket 1 map pinned against the datasheet

## Objective

src/net/w5100.c maps socket 1, the DHCP client's UDP socket: registers at
0x0500, TX ring 0x4800-0x4FFF, RX ring 0x6800-0x6FFF. No test compares those
frames with the datasheet literal, so dropping the TX1 wrap mask passes every
W5100 suite. Pin them in test/unit/test_w5100_spi_mutate.c.
