# #55 W5100/W5500 Ethernet transport: plan

## Objective

The W5x00 chip files' SPI frames are checked on the host against the
datasheets' literals, not only against the software chip models' reading of
them, for every socket space the stack uses.

## Slices

1. W5500 socket 1 block selects (this branch). `test/unit/test_w5500_spi_mutate.c`
   adds three tests: socket 1 registers (BSB 00101), TX buffer (00110) and RX
   buffer (00111), each one write and one read frame compared with literals.
   A mutant `w5500.c` that sends `(space & 3) << 3` fails the three tests.
2. W5100 socket 1 address map (row-55-w5100-socket1-map, a separate lane):
   `test/unit/test_w5100_spi_mutate.c` only.

## Out of scope

- Any edit to `src/`, `mk/`, SPEC or ADR text.
- Hardware runs: nothing is flashed or connected.
