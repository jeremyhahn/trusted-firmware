# Plan: SPEC row stm32h5, open follow-ups (Closes #599)

Carry the open follow-ups of row `stm32h5` (issue #599) on one branch,
`row/599-stm32h5`, and one PR. The row's checklist has one item: #596
(Refs #566), CI builds the `CRYPTO=stm32h5` image for the STM32H573I-DK.

   `.github/workflows/ci.yml` to a `make firmware BOARD=<board>
   CRYPTO=<tier>` step for every tier a board's `profile.mk` declares in
