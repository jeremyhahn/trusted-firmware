3. #869 UART IBRD max: `f70b14a2` (test) and `90873be0` (fix),
   `test/unit/test_rp2350_soc.c` and `src/hal/cortex-m/rp2350/soc_calc.h`.
   This is the PR's only production change. `tfw_rp_uart_divisors`
   (`soc_calc.h:108`) now refuses a 16.6 divisor above 65535 * 64, so IBRD
   65535 never pairs with a nonzero FBRD; [RP-DS] release 8 §12.1.7.1
   `uart_set_baudrate` (lines 164-166) sets FBRD 0 there. Both
   `boot_uart.c` and `hal_uart.c` call it. Only rates whose divisor falls in
   65535 * 64 + 1 .. 65535 * 64 + 63 change, from accepted to refused; no
   integer baud from the board's 12 MHz clk_peri reaches that band.
