# #627: device capabilities (SPEC row)

## Objective

The capability handlers under src/caps say what the code does, in code and in
the comments a reader goes to for the facts they state.

## Slices, in order

1. **caps-drift-batch** (row/627-caps-drift-batch): one batch PR, comments
   only, for drift in src/caps. It fixes the mk/avr.mk cites (the file is
   mk/firmware.mk), the bus gating text, the crypto-provider count, the EEPROM
   boundary (0x140, not 0xC0), the 2560 journal placement, the
   provision_atecc pubkey_read comment, the ALIAS page range (1..), the
   signed-document size bound (365 to 492), and attest.c's caller list. No
   test is added because no behaviour changes. `make host-test`, `make lint`
   and `make releasability` stay green. This slice folds in
   row-627-bus-mk-cites.
2. **timer-cancel-range** (row-627-timer-cancel-range): src/caps/sched.c,
   its own lane and tests.

## Out of scope

- mk/, include/, docs/ pages, src/caps/sched.c in slice 1.
- mk/avr.mk cites outside src/caps (include/tfw/hal.h, src/core/auth_session*.c,
  src/core/handoff_none.c, src/crypto/none/provider.c).
- SPEC and ADR text.
