# Row cortex-m (#628): open follow-ups

## Objective

docs/cortex-m/engineering.md's "tfw-boot enables no interrupt: its UART
polls" is pinned end to end only, in QEMU. Pin it on the host too: a test of
boot/hal/cortex-m/mps2/boot_uart.c over a register model, as the RP2350's
boot UART has (boot/hal/cortex-m/rp2350/test/).

## Slices

1. row/mps2-boot-uart-test (this slice).
   - `boot/hal/cortex-m/mps2/test/test_boot_mps2_uart.c`, built once under
     each MPS2 profile (an500: UART0 at 0x40004000, 25 MHz; an505: UART0 at
     0x40200000, 20 MHz) by `make boot-test`.
   - The model holds UART0's five registers and nothing else: any other
     address fails the test, so the file touches no NVIC, SCB or timer.
   - The model checks CTRL's interrupt enables (TXINT, RXINT, TXOVRINT,
     RXOVRINT) on every register access, so an enable written and cleared
     again between two accesses still fails.
   - Tests: init at 115200 (divisor, overrun clear, TX and RX enabled, no
     interrupt enable); TX writes DATA after TXFULL clears; RX reads DATA
     only when RXFULL is set; the hand-over drains TXFULL, then CTRL and
     BAUDDIV to 0, the overrun and interrupt flags cleared.
   - Refusals: baud 0; a divisor under BAUDDIV_MIN (16), with the edge at
     exactly 16 accepted; TX on a UART never enabled writes nothing and does
     not wait; RX with RXFULL clear leaves the byte alone; the hand-over of a
     UART never enabled does not wait on TXFULL.
   - docs/cortex-m/engineering.md names the host test beside the QEMU one.

2. row/mps2-bus-regs-test.
   - test_mps2_bus, test_mps2_spi_row and test_mps2_optiga link the image's
     sbcon.c and pl022.c instead of re-defining the seven accessors. The
     accessors' TFW_CM_REG goes to test/model/mps2_bus_model.c through
     test/model/cortex-m/mps2/cm_regs.h; the model decodes the address
     against mps2-an505's bases and hands the access to the suite's bus,
     whose old accessor bodies become the tfw_mps2_model_* hooks.
   - A host pointer cannot tell a read from a write, so the link wraps each
     accessor (-Wl,--wrap): the wrap gives the direction, and the model fails
     an accessor that makes no access, more than one, or one at a register
     that direction does not allow, and any access outside an accessor.
   - test_mps2_adc: the image's hal_adc.c under mps2-an505's profile with
     the model linked and every hook failing; init OK, set_ref unsupported
     for each reference, every channel 0..255 refused with the word left.
   - Proof: swapping SB_CONTROLS/SB_CONTROLC fails test_mps2_bus and
     test_mps2_optiga; flipping a PL022 offset fails test_mps2_bus and
     test_mps2_spi_row.

## Out of scope

- The application's UART (src/hal/cortex-m/mps2/hal_uart.c) and its
  interrupt path: it has its own tests.
- A shared home for the register-layer stand-in: the test takes the RP2350
  test's cm_regs.h, which names no SoC.

## Slice 3: boot_hal_cortex-m.c on the host (row/cm-boot-hal-test)

- The jump to the application (barriers, MSP write) moved to boot/hal/cortex-m/boot_jump.c, listed in ARCH_BOOT_SRCS (mk/arch/cortex-m.mk); the rest of boot_hal_cortex-m.c builds on the host.
- boot/hal/cortex-m/test/test_boot_hal_cortex-m.c (mk/boot.mk, built under mps2-an505 and mps2-an500): page size, page writes inside/below/past the region and unaligned, nvm block range, handoff round trip, factory copies before the reset cause, reset, watchdog.
- Fix: tfw_boot_flash_write_page compared addr + page > end, which wraps for the last page of the address space; it now compares addr > end - page, with a static assert that the region holds a page. The wrap test failed before the fix.
- Not run here: make integration-test-cortex-m (no arm-none-eabi-gcc on this node); the QEMU boot tests are what exercise boot_jump.c.

## Folded slices (PR #849)

Each slice below has its changelog.d/628-<slice>.md entry. Unless a bullet
says "fix:", the slice adds or tightens tests only and changes no source.

- cm-fault-misalign: pins tfw_cm_fault_keep()'s stack alignment mask (Cortex-M fault record); test/unit/test_cm_fault_frame.c, test_a_stack_pointer_one_or_three_bytes_off_is_not_read.
- cm-mpu-smallest-boot: pins the MPU table's smallest (32-byte) tfw-boot region from hal_mpu.h; test/unit/test_cm_mpu.c, test_the_smallest_boot_region_is_accepted.
- cm-sys-handoff-cause: pins the Cortex-M hal_sys tfw_hal_reset_cause() hand-off and tfw_hal_init(); test/unit/hal/test_cortexm_sys.c, test_every_handed_off_cause_comes_back_unchanged and test_init_is_ok.
- imx95-tpm-reprogram: pins the i.MX 95 TPM PWM write's reprogram of a counter at a stale MOD or with CPWMS set; test/unit/test_imx95_tpm.c, test_tpm_a_counter_at_another_period_or_mode_is_reprogrammed.
- lpi2c-clean-start: pins the FRDM-MCXN947 LPI2C master's transfer start (stale flag, both FIFOs) and a STOP that never shows; test/unit/test_mcxn_lpi2c.c, test_a_flag_left_from_before_is_cleared_at_the_start, test_a_byte_left_in_the_receive_fifo_is_not_read, test_a_command_left_in_the_transmit_fifo_is_not_run and test_a_stop_that_never_shows_is_a_timeout_and_aborted.
- lpi2c-clkhi-zero: pins the LPI2C timing search's CLKHI 0 refusal; test/unit/test_mcxn_lpi2c.c, test_a_rate_whose_clkhi_would_be_zero_is_refused.
- lpi2c-five-percent: pins the LPI2C timing search's 5 % bound; test/unit/test_mcxn_lpi2c.c, test_the_five_percent_bound_is_inclusive.
- lpi2c-late-flags: pins the LPI2C master's NACK kept when a flag shows after the error flush, and the receive FIFO flushed on a failed read; test/unit/test_mcxn_lpi2c.c, test_a_refused_byte_keeps_its_nack_when_the_stop_meets_a_new_flag, test_a_refused_byte_keeps_its_nack_when_its_stop_raises_a_flag and test_a_failed_read_flushes_the_receive_fifo.
- lpi2c-prescale-edges: pins the LPI2C timing search's prescale tie and its 120 - SCL_LATENCY cycle ceiling; test/unit/test_mcxn_lpi2c.c, test_a_tie_goes_to_the_smaller_prescale and test_the_cycle_ceiling_is_inclusive.
- lpi2c-slowest-rate: pins the LPI2C timing search's last prescale (766 Hz timed, 765 Hz refused); test/unit/test_mcxn_lpi2c.c, test_the_slowest_rate_takes_the_last_prescale.
- lpi2c-stop-after-error: pins the LPI2C master's STOP that cannot be queued or never shows, after the last byte or a refusal; test/unit/test_mcxn_lpi2c.c, test_a_stop_that_cannot_be_queued_is_a_timeout_waited_once, test_a_refused_byte_whose_stop_cannot_be_queued_is_nack and test_a_refused_byte_whose_stop_never_shows_is_nack.
- mcxn-adc-gain-sides: pins the MCXN94x LPADC's per-side gain calibration (each GCR from its own GCC); test/unit/test_mcxn94x_adc.c, test_each_side_takes_its_own_gain.
- mcxn-boot-uart-waits: pins the FRDM-MCXN947 tfw-boot UART's TDRE and TC waits; boot/hal/cortex-m/mcxn94x/test/test_mcxn_uart.c, test_putc_waits_for_room_before_it_writes and test_stop_waits_for_the_shifter_not_the_buffer.
- mcxn-flash-past-end: pins the FRDM-MCXN947 tfw-boot flash write's refusal of a start past the end of the flash; boot/hal/cortex-m/mcxn94x/test/test_mcxn_flash.c, test_a_span_outside_the_flash_is_refused (extended).
- mcxn-gpio-input-modes: pins the MCXN94x GPIO pull-up over another pin function and both input modes on port 1; test/unit/test_mcxn94x_gpio.c, test_input_pullup_replaces_another_function and test_inputs_on_port_1_use_port1_and_gpio1.
- mcxn-lpi2c-error-flags: pins the LPI2C master's lost arbitration, pin low timeout and FIFO error statuses; test/unit/test_mcxn_lpi2c.c, test_each_error_flag_is_its_own_status_and_stopped.
