# #635 application SDK follow-ups: the row PR's plan

## Objective

One PR for the SPEC row "application SDK" (docs/SPEC.md), as the factory
carries every SPEC row (one PR per row, DS-10127). The row PR is #859
(branch row/635-app-mk-refusals). PR #758, the docs drift batch, and the
other per-item PRs named below were merged into it (merge commits, never
squashed) and closed with a pointer here. The scope is the row, not only
the docs batch. Every item is a docs correction, a test, or a fix that has
a test. The fixes change production behaviour, each with a test that fails
without it: scripts/app_symbols.py (item 3), `tfwctl app` (item 10),
mk/app.mk (item 14b), sdk/go/cmd/tfwctl/main.go (item 20) and
src/crypto/soft/id_p256.c (item 21). No SPEC or ADR decision text
changes, and no hardware is used.

## Items, in landing order, with the test each adds

1. Docs drift: the alias TBS is 400 bytes (249 + 151), and the app ADRs
   cite current lines (architecture.md, dice engineering.md, the
   ACME-finalize ADR, the pin-reservation and wire-commands ADRs).
2. tfw_app_config_write returns the EEPROM's status when the HAL refuses
   the write: test/unit/test_app_state_wire.c, test/mock/hal_mock.[ch].
3. scripts/app_symbols.py exits 2, not the "no symbol" 1 that
   mk/arch/esp32-targets.mk accepts, on an unreadable ELF or an
   out-of-range string-table link: scripts/test_app_symbols.py. Before the
   fix a missing ELF raised a traceback (rc 1), so esp32-build passed an
   image it never read.
4. The Go SDK's AppState and APP_INFO widths are pinned to app_runner.h,
   app.h and protocol.h: scripts/test_app_info_mirror.py.
5. The runner's overrun count holds across the millisecond wrap:
   test/unit/test_app_runner_mutate.c.
6. The no-application build attests the firmware hash:
   test/unit/test_app_none.c.
7. The 2560 store image serves TFW_OTA_SLOTS to an application:
   test/unit/test_sys_store.c.
8. Claim 273 is the firmware hash after a stop for an update:
   test/unit/test_app_measurement.c (PR #933).
9. The trial deadline holds across the 32-bit wrap:
   test/unit/test_ota_trial.c (PR #919).
10. `tfwctl app` takes no argument, as cli.md says: sdk/go/cmd/tfwctl
    (PR #950).
11. A RESET stops the application only after its reply drains:
    test/unit/test_app_reset_drain.c (PR #969).
12. On ESP32 the application link refuses RESET(1) when there is no
    tfw-boot session: test/unit/test_esp_app_ota.c (PR #974).
13. The example's init refuses when the HAL refuses its pin:
    test/unit/test_app_example.c (PR #994).
14. mk/app.mk's APP_DIR gate: scripts/test_app_mk.py pins every refusal
    an out-of-tree application meets before anything is compiled
    (changelog.d/635-app-mk-refusals.md).
    14b. Fix: an APP_SRCS entry with a `..` component anywhere is refused
    (mk/app.mk lines 48-54; the `sub/../../x.c` case in
    scripts/test_app_mk.py; changelog.d/635-app-srcs-dotdot.md).
15. An application built against an older ABI is refused:
    test/unit/test_app_abi.c (PR #941; changelog.d/635-app-older-abi.md).
16. APP_DIR names the firmware build directory: scripts/test_build_dirs.py
    (PR #1016; changelog.d/635-app-dir-build-dir.md).
17. The empty runner's surface matches app_runner.h:
    scripts/test_app_runner_none.py (PR #1030;
    changelog.d/635-app-none-surface.md).
18. The AVR tick count carries through all 32 bits:
    test/unit/hal/test_avr_tick_mutate.c (PR #1039;
    changelog.d/635-avr-millis-carry.md).
19. Every ATTEST_ALIAS mint reads the application's evidence afresh:
    test/unit/test_alias.c (changelog.d/635-alias-remint-evidence.md).
20. Fix: `tfwctl reset` refuses a mode other than soft or boot:
    sdk/go/cmd/tfwctl/main.go, main_test.go
    (changelog.d/635-reset-mode-refused.md).
21. Fix: the soft P-256 identity returns TFW_ERR_CRYPTO when micro-ecc
    refuses: src/crypto/soft/id_p256.c, test/unit/test_soft_id_p256.c
    (changelog.d/635-soft-id-refused.md).
22. APP_CMD `0x07`, per the wire-commands ADR as accepted by owner ruling
    1243 (one id with an `app_op` byte, the application gates per sub-op
    through tfw_app_session_ok(), BAD_STATE widened, serial only): host
    side sdk/go CmdAppCmd, Device.AppCommand and `tfwctl app-cmd`; device
    side tfw_app_command, src/core/app_cmd_none.c and `APP_COMMANDS := yes`
    in app.mk. Tests: test/unit/test_app_cmd.c, test_app_cmd_gate.c,
    test_app_cmd_none.c,
    test_app_example.c, test_app_none.c, test_link_eth.c,
    scripts/test_app_mk.py and the TFWV_APPCMD_* vectors
    (changelog.d/635-app-cmd-docs.md and the lanes' entries).

Each item has its own changelog.d/635-*.md entry. Earlier, the row's
first slice (row/app-symbols-test, #636, main f46e1c3f) gave
scripts/app_symbols.py its test, scripts/test_app_symbols.py, run by

commits into row/635-app-mk-refusals (PR #859); no new behaviour.
