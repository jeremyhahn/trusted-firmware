batches the drift into one PR per subsystem; each lane below is one batch.

## Slice: HSM self-defence batch (branch `row/640-hsm-drift-batch`)

Pages: `docs/hsm-self-defence/README.md`, `architecture.md`, `m7-design.md`,
`adr-response-policy-format.md`, `adr-a6-durable-store.md`.

1. README and architecture: slice 3 links the engine and its loop into the
   mps2-an505 QEMU image (`boards/mps2-an505/profile.mk`, `HSM := 1`); the
   channel also carries `HSM_RECORD_READ` `0x7C`; lockdown sends A1, A2, A3,
   A6 and a port that cannot lock answers `TFW_ERR_UNSUPPORTED`.
2. m7-design: the port's four functions (act, key, sense, measure), its
   implementations (tfwsim, mps2, i.MX 95, unit tests), what H1 still
   lacks, and every done slice (1-11b-2).
3. The two ADRs: `suit.h` line cites, `tfw_suit_read_integrated` takes the
   key, the A6 store's `tfw_status_t` returns (#295), the ATECC data helpers
   (#293) and the model's two counters. Context and "what waits" lines only;
   no decision or open-question wording changes, an answered question gets
   "Answered on main: ..." appended. EEPROM layout text (Q-EEPROM-1) kept.

Tests: docs only. Acceptance is `git grep` of the stale phrases (none), of
each cited file:line (all hit), and `make releasability`.
